# FlixCore

High performance core systems plugin for Flix Studios.

### Installation
Download the latest release jar from [GitHub Releases](https://github.com/tejasjhain-sudo/FlixCore/releases/latest) and place it in your server's `plugins/` directory.

### Commands
- `/fc help` - Display help menu
- `/fc update` - Check and download updates
- `/fc version` - Display current build version
